# Contributing

Project Manager is in its initial planning phase. See the [roadmap](docs/roadmap.md) and GitHub issues for current work.

- Discuss substantial changes in an issue before implementing them.
- Keep pull requests focused and explain the user-visible result.
- Include validation appropriate to the change and disclose what was not tested.
- Preserve human-authored notes, attribution, activity history, and concurrent changes.
- Use synthetic projects and data in examples, screenshots, fixtures, and tests.
- Do not commit credentials, real project inventories, private server addresses, or runtime databases.

Documentation contributions in English or Korean are welcome. Contributions are provided under the repository's MIT license.

There are no application build or test commands yet. Add reproducible setup and validation instructions alongside the first implementation.
