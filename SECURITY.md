# Security policy

This project is pre-release and has no supported application release yet.

The intended deployment is a private Tailscale network with application authentication. Public internet exposure is outside the initial deployment scope. Network membership must not substitute for application authentication.

Never include credentials, private project details, logs containing secrets, or private server addresses in public issues. For a vulnerability that cannot safely be disclosed publicly, use GitHub private vulnerability reporting if it is enabled. Otherwise, open an issue requesting a private contact channel without including exploit details or sensitive data.
